# Portafolio Personal

Portafolio personal desarrollado como proyecto académico para la asignatura
Ingeniería de Software I, aplicando control de versiones con Git y GitHub.

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

- develop: integración de funcionalidades
- feature/RWGC-add-header
- feature/RWGC-add-inicio
